
* Installing dameformats

#+BEGIN_SRC sh
$ mkdir venv-dameformats
$ python3 -m venv venv-dameformats
$ cd venv-dameformats
$ source bin/activate
$ pip3 install dameformats
#+END_SRC

* Executing tests:
** All test
#+BEGIN_SRC sh
$ cd dameformats
$ ./runtests.sh
#+END_SRC
** Single test's file
#+BEGIN_SRC sh
$ cd dameformats
$ pytest tests/test_damecsv.py
#+END_SRC
** Single test
#+BEGIN_SRC sh
$ cd dameformats
$ pytest tests/test_damecsv.py::TestDameCsv::test_damecsv_csvcolumn2list 
#+END_SRC

* Making a Pypi package
+ To install from local:
#+BEGIN_SRC sh
$ pip install -e .
#+END_SRC

+ To install create tar.gz in dist directory:
#+BEGIN_SRC src
$ python3 -m build
#+END_SRC

+ To upload to pypi:
#+BEGIN_SRC src
$ twine upload dist/dameformats-0.1.tar.gz
#+END_SRC
